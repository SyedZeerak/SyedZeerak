## 🚀 Selected Projects

### 🚦 SafeRaah — AI-Powered Road Accident Detection *(Final Year Project)*
Real-time accident detection from traffic camera feeds using RF-DETR, with automated alerting through the Gemini API and WhatsApp integration. Recognized by the **Ignite National Technology Fund**.

![RF-DETR](https://img.shields.io/badge/RF--DETR-8A2BE2?style=flat-square) ![Gemini](https://img.shields.io/badge/Gemini_API-4285F4?style=flat-square&logo=google&logoColor=white) ![React](https://img.shields.io/badge/React-20232A?style=flat-square&logo=react&logoColor=61DAFB) ![Flask](https://img.shields.io/badge/Flask-000000?style=flat-square&logo=flask&logoColor=white) ![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white)

### 📦 Retail SKU Recognition *(PepsiCo Internship, 2025)*
Trained YOLOv11 for retail shelf SKU detection, reaching 90% mAP@50 on a self-collected and annotated dataset of 1,000+ images, validated in live retail environments.

![YOLOv11](https://img.shields.io/badge/YOLOv11-111111?style=flat-square) ![OpenCV](https://img.shields.io/badge/OpenCV-27338e?style=flat-square&logo=opencv&logoColor=white) ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

### 🧠 Gated Mixture-of-Experts for Salary Prediction
Custom MoE architecture trained on scraped job-market data, improving prediction R² from 0.21 to 0.90 using TF-IDF and SVD feature pipelines.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Scikit-learn](https://img.shields.io/badge/scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white)

### 🗺️ Socioeconomic Clustering of Pakistani Districts
Unsupervised clustering (KMeans, PCA, t-SNE) across 130+ districts to surface socioeconomic patterns relevant to policy analysis.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Clustering](https://img.shields.io/badge/Clustering-FF6B6B?style=flat-square)
